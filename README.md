# SUR Restaurant & Lounge Website

## Project
A four-page HTML website project about SUR Restaurant & Lounge in West Hollywood, California.

## Restaurant
SUR Restaurant & Lounge is a New American restaurant and lounge. The restaurant describes its decor as eclectic, combining an old-world European atmosphere with Asian accents. It has several dining spaces, a bar lounge, and an outdoor garden.

## About This Project
This project is being built for a web design course. Part 2 focuses on creating the HTML structure and real content for the homepage, about page, menu page, and contact page. CSS styling will be added in Part 3.

## Pages
- `index.html` - Homepage
- `about.html` - Restaurant story and information
- `menu.html` - Dinner menu with more than 12 menu items
- `contact.html` - Address, contact information, hours, and embedded map
- `images/` - Image source notes and attribution

## Technologies
- HTML5
- Semantic HTML elements
- Google Maps iframe embed
- External links to restaurant and reservation information

## Image Notes
The HTML currently uses externally hosted photographs of SUR's patio, dining spaces, and bar. The `images/README.md` file lists the image sources and suggested local filenames. For a fully self-contained submission, download images that you are permitted to use into the `images/` folder and update the image paths in the HTML files. Check image usage rights before publishing them.
